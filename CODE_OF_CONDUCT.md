# Code of Conduct

This project uses a simple standard: be respectful, constructive, and specific.

Contributors should:

- focus criticism on code, design, data, and tradeoffs
- assume good intent while still asking for clear evidence
- avoid harassment, personal attacks, and discriminatory language
- protect private customer or company information

Maintainers may remove comments, issues, pull requests, or contributors that make
the project unsafe or unproductive.
