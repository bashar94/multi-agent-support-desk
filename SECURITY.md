# Security

Do not include real customer messages, credentials, API keys, access tokens, or
private business data in issues, pull requests, screenshots, or sample files.

## Reporting

If you find a security issue, open a private report through GitHub security
advisories when the repository is published. Until then, contact the repository
owner privately.

## Local Data

The default SQLite database is stored under `.data/` and is ignored by Git.
Delete that directory when you want to reset local demo data.
